# SWK Properties UAE — static site

Warm light theme (cream canvas, deep navy ink, tan/gold accents), serif display type, full-bleed video hero, scroll-driven 3D depth, header navigation, glow listing cards.
No runtime dependencies. Output is plain static files in `public/`.

## Build

```bash
python3 build.py          # Python 3.9+, stdlib only
```

Reads `data/*.json`, `src/css`, `src/js`, `src/root`. Writes `public/` (462 pages, clean directory URLs, sitemap, robots, assets with a content-hash version).

Edit content in `data/` (developers, communities, services, team, blog, faq, site), then rebuild and commit `public/`. `data/developers.json` is generated by `tools/make-developers.py`; project names and locations come from each developer's public site and should be re-verified before publishing. No prices or unit details are published.

## Preview and test

```bash
node tools/dev-server.js 8765      # serves public/, draws SVG placeholders for missing /assets/images/*
PLAYWRIGHT_PATH=/opt/node22/lib/node_modules/playwright node tools/qa.js
```

`tools/qa.js` checks every page (console errors, SEO tags, links, alt text, overflow, axe), the hero scroll scrub, slider, lightbox, filters, calculator maths, forms, a 320–1920px layout sweep, reduced motion, `?nowebgl` and no-JS. Optional: `AXE_PATH` (axe-core file), `SHOTS` (screenshot dir).

## Hero video

The home hero is one muted, looping `<video>` (`src/assets/video/hero-swk.mp4`, H.264 High, no audio track, `faststart`) that fills the hero with `object-fit: cover`. There are no overlays or tints on top of it; the copy is white with a soft text shadow. `hero-swk-poster.webp` is the first frame: it is the `poster`, the LCP preload, and what reduced-motion and data-saver visitors see (`40-hero.js` skips playback for them). The clip also pauses while the hero is off screen or the tab is hidden.

To replace the clip, re-encode the source with no audio and a web-friendly layout, and regenerate the poster from its first frame:

```bash
ffmpeg -i source.mp4 -an -c:v libx264 -preset veryslow -profile:v high -pix_fmt yuv420p -crf 19 -movflags +faststart src/assets/video/hero-swk.mp4
ffmpeg -i source.mp4 -frames:v 1 -c:v libwebp -quality 92 src/assets/images/hero/hero-swk-poster.webp
```

The current source is 720x1280 portrait, so on a wide desktop `cover` crops it to a horizontal band and enlarges it. For the sharpest result on large screens, supply a 16:9 clip at 1920x1080 or higher.

## Deploy

Upload `public/` to any static host. `vercel.json` sets the output directory, redirects and headers; `public/.htaccess` covers Apache (HTTPS/www redirect, old URL 301s, caching).

Brand assets live in `src/assets/` and the build copies them into `public/assets/`. The logo is the corporate gold set generated by `tools/make-gold-logo.py` from `swk-logo-navy.png` (the original artwork); run it, then `tools/make-icons.py`, if the artwork changes.

- `images/brand` logo, favicon, cursor · `images/hero` · `images/developers` (marquee logos `logo-01..10`) · `images/team` · `images/about` · `images/blog` · `images/communities` · `images/gallery` (`image1..25`)
- `images/projects/{developer-slug}/{project-slug}.{webp|jpg|png}`: licensed project renders. Where one exists it replaces the generated SWK illustration on the project card and developer page
- `fonts/instrument-serif` (display, regular + italic) and `fonts/general-sans` (UI and body, 400-700), declared in `src/css/base.css`. All fonts are self-hosted; nothing loads from Google. `fonts/clash-display` is kept but no longer used.

Add new files under `src/assets/`, never directly in `public/` (the build deletes and regenerates it).

## Needs your input

- `data/testimonials.json` is empty on purpose. Add only real client statements, each with the client's written approval, in the format of `data/testimonials.example.json` (`approved: true` is required to show an entry; `flag` is the 2-letter country code). Until then the home page shows service commitments instead.

- `data/site.json` `formEndpoint` is empty. Until set, forms open the visitor's mail app and never claim a message was received.
- `brn` and `tradeLicense` are empty. Fill them in for the footer and legal pages.
- FAQ fee wording (for example the "AED 4,200" DLD admin fee and housing-fee text) is kept from the original site. Verify it before relying on it.
- Privacy and Terms are templates. Have them reviewed.

## Theme and motion

- Colours and fonts are tokens in `src/css/variables.css`. Navy bands (CTA, newsletter, stats, lightbox) re-scope the tokens via `.on-dark`, so components inside them need no overrides.
- Navigation: a top bar on desktop (`.site-header`); on tablet and phone the same header carries a menu button (links, consultation, call, WhatsApp, chat), so there are no floating buttons at the bottom of the screen. `src/css/theme.css` (loaded last) holds page transitions, skeleton loaders and scroll-scrubbed 3D entrances; `src/js/modules/35-scroll3d.js` drives them. Everything is off under `prefers-reduced-motion`.
- Loading: the main fonts are preloaded, `<img>` tags get intrinsic `width`/`height` read from the files at build time, images show a skeleton until decoded, and the preloader only appears on slow loads.

## Notes

- Home developers and spotlight are single-row, swipeable carousels (`row_carousel` in `build.py`, `src/js/modules/63-row-carousel.js`); other pages keep grids.
- An earlier audit counted "14 listings" as a bug. That was real pagination (9 per page). It also said split-text headings lacked accessible text; the original already used sr-only text with `aria-hidden` letters.

## Site-wide UI, SEO and compliance

- `data/site.json` controls the announcement bar (`announcement`), newsletter pop-up (`popup`), analytics IDs (`analytics.ga4/gtm/metaPixel`, loaded only after cookie consent), search-console verification (`verification`) and `twitter`.
- Cookie banner + preferences, toasts, callback modal, back-to-top: `src/js/modules/75-ui.js`, `src/css/ui.css`.
- Each page gets a meta CSP with computed script hashes (`csp_for` in `build.py`); extra headers live in `vercel.json`.
- Generated: `sitemap.xml` (with images), `robots.txt`, `feed.xml`, `manifest.webmanifest`, `.well-known/security.txt`, `/cookies/`.
- `python3 tools/make-icons.py` rebuilds favicon/PWA icons. Hero poster is `src/assets/images/hero/hero-swk-poster.webp`.
